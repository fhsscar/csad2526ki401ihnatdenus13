Промпт:
"Generate a GitHub Actions workflow YAML file for a C++ project with CMake and Google Test, triggered on push/pull_request for develop and master branches."
"Add a matrix strategy to the GitHub Actions workflow for ubuntu-latest, windows-latest, and macos-latest."
"Add a deploy step to upload artifacts in the GitHub Actions workflow."
Відповідь:
To create a GitHub Actions workflow for building and testing a C++ project with CMake, I'll define a ci.yml file that meets your requirements.


name: Build and Test C++ Project

on:
  push:
    branches:
      - develop
      - master
  pull_request:
    branches:
      - develop
      - master

jobs:
  build-and-test:
    runs-on: ${{ matrix.os }}

    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]

    steps:
    - name: Checkout code
      uses: actions/checkout@v4

    - name: Set up CMake
      uses: jwlawson/actions-setup-cmake@v1

    - name: Configure CMake
      run: cmake -S . -B build

    - name: Build
      run: cmake --build build --config ${{ matrix.os == 'windows-latest' && 'Debug' || '' }}

    - name: Run tests
      run: ctest --test-dir build --output-on-failure ${{ matrix.os == 'windows-latest' && '-C Debug' || '' }}

    - name: Upload artifacts
      uses: actions/upload-artifact@v3
      with:
        name: build-artifacts
        path: build/Debug/
